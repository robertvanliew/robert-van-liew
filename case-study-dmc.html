DMC Canada '26

UI/UX DESIGN | CUSTOM CODE ON SQUARESPACE | E-COMMERCE

Role

Product Designer & Lead Engineer

Timeline

1 Week Sprint

Tech Stack

Squarespace, custom CSS and JS (code injection), Stripe

Deliverables

Brand System, Custom Code, Shop and Ticketing

Live

dmcdjcanada.com

The Challenge

The DMC World DJ Championships needed a full digital overhaul for their Canadian division. The brief was to build a platform that captured the underground energy of battle DJing while running a clean e-commerce flow for tickets and official merchandise.

The legacy system was fragmented and didn't perform well on mobile devices, leading to cart abandonment during high-traffic ticket drops. My goal was to unify the brand and the checkout experience in one site the organizers could keep running themselves on Squarespace.

The Solution

I designed a dark-themed, glassmorphic UI system with stark red contrasts to evoke competition and energy, then built it as custom CSS and JavaScript injected site-wide through Squarespace's header code injection: Bebas Neue and Barlow, an injected hero, a contact panel, and a live ticker. The shop, product pages, and cart were restyled mobile-first, because most ticket buyers arrive on a phone.

How the Custom Code Works

Everything custom lives in Squarespace's header code injection. It defines a small set of DMC color tokens (black, red, grey, white), restyles Squarespace's own sections to match the competition brand, and runs a short script that injects what the template can't make on its own: a hero overlay with two calls to action, Enter The Battle and View Bootcamps, and a red ticker under the hero that loops "DMC Canada '26 · Battle Ready · Online, Open To DJs Worldwide · Register Now."

The script checks whether each piece already exists before adding it, so nothing doubles up when Squarespace re-renders a page. Because the content itself still lives in Squarespace, the organizers keep editing events, products, and copy in the editor they already know.

Payments Left Where They Can't Break

Squarespace doesn't let custom code touch its checkout, and for a ticket drop that is a feature: the payment path is the one part of the site that can't be broken by a design change. I connected Stripe as the payment processor and turned on Apple Pay and Google Pay, so buyers on a phone can pay without typing a card number. My custom code stops at the cart; checkout stays on the platform.

What Broke

Working inside Squarespace means fighting its markup. Every custom element sits on top of a template I don't control, so selectors can break when the platform ships an update. The overrides lean on Squarespace's own section classes, which means the site needs a visual check whenever Squarespace changes its templates.

Sprint Results

Delivered in one week under a hard event deadline. Stakeholder sign-off came in a single design review, with no revision rounds on visual direction, and the build scored 94 on Lighthouse. The result is one dark, competition-ready brand across ticketing, official merchandise, bootcamps, event information, and battle registration.
